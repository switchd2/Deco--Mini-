IC 74148 8-to-3 Priority Resolver

8:3 Priority Encoder

The 74148 encodes eight active-low data request lines (Ī0 through Ī7) into an active-low 3-bit binary code (Ā2, Ā1, Ā0) corresponding to the highest-priority active input. Input Ī7 has the absolute highest priority, while Ī0 possesses the lowest. Active-low logic means logic LOW (0) indicates an active signal, while HIGH (1) represents idle. The IC includes an active-low Enable Input (ĒI), a Group Select status line (ḠS) indicating whether any input is asserted, and an Enable Output (ĒO) for seamless multi-stage priority cascading.

Data Request Inputs Active-Low

Ī0 to Ī7 (0 = Active)

8 priority lines. Ī7 highest priority down to Ī0. Lower inputs are ignored if higher is 0.

Enable Input Active-Low

ĒI (Pin 5)

Must be held LOW (0) to activate encoding. When HIGH (1), all outputs are locked HIGH.

Address Outputs Active-Low Code

Ā2, Ā1, Ā0

Inverted 3-bit binary representation of the winning highest active channel index.

Status & Cascade Flags ḠS & ĒO

ḠS (Group) & ĒO (Cascade)

ḠS = 0 when an input is valid. ĒO = 0 when enabled but NO inputs are asserted (cascading).

Boolean Expression & Logic Equation

Internal logic synthesizes each active-low binary output by gating the enabled priority minterms:

Ā2 = ( ĒI' · ( Ī4'·Ī5·Ī6·Ī7 + Ī5'·Ī6·Ī7 + Ī6'·Ī7 + Ī7' ) )'

Note that when all inputs are inactive HIGH, ĒO = 0 (LOW), asserting the enable input of a cascaded secondary encoder IC!

Practical Applications

Where 8:3 priority encoders are deployed in microcomputer hardware.

Microprocessor Interrupt Controllers

Resolves simultaneous hardware interrupt requests (IRQs). If a critical timer and a keyboard interrupt arrive at the same instant, the encoder prioritizes the timer and feeds its vector code to the CPU.

Flash Analog-to-Digital Converters (ADC)

Thermometer-code outputs produced by an array of high-speed voltage comparators are converted into clean 3-bit binary words using a 74148 priority encoder stage.

Shared Bus Arbitration

Determines which master device on a shared multiprocessor bus gets immediate bus grant permissions when multiple peripheral controllers assert bus request flags concurrently.

Cascaded 16:4 & 64:6 Priority Systems

By connecting the Enable Output (ĒO) of the high-order chip directly into the Enable Input (ĒI) of the low-order chip, multi-chip systems prioritize 16, 32, or 64 input lines flawlessly.
