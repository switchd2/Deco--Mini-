IC 74153 Dual 4-to-1 Data Selector

4:1 Multiplexer

A 4:1 Multiplexer (Data Selector) steers one of four binary data input channels (D0, D1, D2, D3) to a single output channel (Y) under the control of a 2-bit binary address select bus (S1, S0). The classic TTL IC 74153 contains two independent 4-line multiplexers on one chip, each equipped with an active-low Strobe/Enable input (Ḡ). When the strobe is HIGH (1), the output is forced LOW (0) regardless of the data or select lines.

Data Inputs Active-High

D0, D1, D2, D3

Four independent binary inputs carrying signal data to be selected.

Address Select Lines Binary Coded

S1 (MSB), S0 (LSB)

2-bit binary control code addressing channel index 0 (00), 1 (01), 2 (10), or 3 (11).

Enable Strobe Active-Low

Ḡ (Pin 1 / 15)

Active-low chip enable. When Ḡ = 0, the circuit is active. When Ḡ = 1, output Y = 0.

Data Output Non-Inverted

Y

Routes the logical state of the addressed input line when Ḡ = 0.

Boolean Expression & Logic Equation

The output Y can be expressed algebraically as a Sum-of-Products (SOP) expanded with minterms of the select lines and gated by the active-low enable strobe:

Y = Ḡ' · ( S1'·S0'·D0 + S1'·S0·D1 + S1·S0'·D2 + S1·S0·D3 )

When Ḡ = 0 (Ḡ' = 1), exactly one AND product term is activated by the select lines, transferring the corresponding data bit to the OR gate output.

Practical Applications

Where 4:1 multiplexers are utilized in modern computer engineering and communication systems.

Data Routing & Bus Multiplexing

Enables multiple peripheral devices or registers in an 8-bit or 16-bit CPU architecture to share a common internal data bus without electrical contention.

Universal Logic Generator

Any arbitrary 2-variable Boolean function (or 3-variable function using one variable connected to data lines) can be implemented directly using a single 4:1 MUX without external logic gates.

Parallel-to-Serial Conversion

Used in serial communication transmitters (UART) where a multi-bit parallel register is sampled sequentially into a serial transmission wire by cycling the select address lines with a clock counter.

ALU Operation Selection

Steers the selected output from adder, subtractor, AND, or OR functional units to the accumulator destination based on CPU instruction opcode bits.
