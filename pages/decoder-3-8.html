IC 74138 3-to-8 Line Inverting Decoder

3:8 Inverting Decoder

The 74138 is a high-speed 3-line to 8-line inverting decoder/demultiplexer. It accepts a 3-bit binary address word (A2/C, A1/B, A0/A) and asserts exactly one of eight active-low outputs (Ȳ0 through Ȳ7) by driving it to logic LOW (0). The IC features a sophisticated 3-line gating enable architecture comprising one active-high input (G1) and two active-low inputs (Ḡ2A and Ḡ2B). The device functions only when G1 = 1, Ḡ2A = 0, and Ḡ2B = 0; otherwise, all eight outputs are locked HIGH (1).

Address Inputs 3-bit Binary

A2 (C), A1 (B), A0 (A)

3 binary inputs selecting minterms m0 (000) through m7 (111). A2 is the MSB.

Active-High Enable G1

G1 (Pin 6)

Must be held HIGH (1) for normal decoder operation.

Active-Low Enables Dual Strobes

Ḡ2A & Ḡ2B (Pins 4, 5)

Both strobes must be held LOW (0) to permit decoding.

Decoded Outputs Active-Low

Ȳ0 through Ȳ7

8 mutually exclusive outputs. The addressed output goes LOW (0); all others remain HIGH (1).

Boolean Expression & Logic Equation

Internal enable condition: E = G1 · Ḡ2A' · Ḡ2B'.
Each active-low output is synthesized through an internal 4-input NAND gate evaluating the enable and the corresponding address minterm:

Ȳ0 = ( E · A2' · A1' · A0' )' = E' + A2 + A1 + A0
Ȳ1 = ( E · A2' · A1' · A0 )' = E' + A2 + A1 + A0'
Ȳ2 = ( E · A2' · A1 · A0' )' = E' + A2 + A1' + A0
Ȳ3 = ( E · A2' · A1 · A0 )' = E' + A2 + A1' + A0'
Ȳ4 = ( E · A2 · A1' · A0' )' = E' + A2' + A1 + A0
Ȳ5 = ( E · A2 · A1' · A0 )' = E' + A2' + A1 + A0'
Ȳ6 = ( E · A2 · A1 · A0' )' = E' + A2' + A1' + A0
Ȳ7 = ( E · A2 · A1 · A0 )' = E' + A2' + A1' + A0'

Because NAND outputs are active-low, connecting the outputs directly to an external NAND gate implements any arbitrary Boolean function in canonical Sum of Products (SOP) form!

Practical Applications

Essential systems utilizing 3:8 decoders across hardware architectures.

Microprocessor Memory Address Decoding

Maps 64KB memory spaces into eight 8KB blocks by routing higher-order address lines A15..A13 to 74138 address inputs to drive SRAM/EEPROM chip enable pins.

Seamless IC Expansion (1-of-16, 1-of-32)

Two 74138 ICs can be cascaded to build a 4:16 decoder without external inverters: address line A3 is simply wired to G1 on one chip and to Ḡ2A on the other.

I/O Port Address Strobe

Controls peripheral chips (parallel I/O, UARTs, timer counters) in bus-based embedded designs by generating isolated read/write chip select strobes.

1-of-8 Data Demultiplexer

By wiring data to enable pin Ḡ2A (with G1=1 and Ḡ2B=0), the 74138 acts as a complete 1:8 demultiplexer routing serial data to one of eight output lines.
