IC 74139 Dual 2-to-4 Inverting Demux

1:4 Demultiplexer

A 1:4 Demultiplexer (Data Distributor) accepts a single data input stream and distributes it to one of four output channels determined by a 2-bit binary select address (S1, S0). The standard TTL IC 74139 contains two identical 2-to-4 line decoder/demultiplexers. Each section is controlled by an active-low Enable strobe (1Ḡ) and features active-low outputs (1Ȳ0 through 1Ȳ3). When disabled (1Ḡ = 1), all outputs are held inactive HIGH (1). When enabled (1Ḡ = 0), the selected output drops to LOW (0) when active data is routed.

Data Input Data Line

Din

Address Select Bus 2-bit Binary

S1 (B), S0 (A)

2-bit binary address selecting channel 0 (00), 1 (01), 2 (10), or 3 (11).

Enable Strobe Active-Low

1Ḡ (Pin 1)

Active-low strobe. When 1Ḡ = 0, decoding is enabled. When 1Ḡ = 1, all outputs remain HIGH.

Outputs (Section 1) Active-Low

Inverting active-low outputs. A logic 0 represents the active/asserted channel state.

Boolean Expression & Logic Equation

Each output line of the 74139 is formed by an active-low NAND gate combining the enable strobe, address minterms, and routed data:

1Ȳ0 = ( 1Ḡ' · S1' · S0' · Din )' = 1Ḡ + S1 + S0 + Din'
1Ȳ1 = ( 1Ḡ' · S1' · S0 · Din )' = 1Ḡ + S1 + S0' + Din'
1Ȳ2 = ( 1Ḡ' · S1 · S0' · Din )' = 1Ḡ + S1' + S0 + Din'
1Ȳ3 = ( 1Ḡ' · S1 · S0 · Din )' = 1Ḡ + S1' + S0' + Din'

Notice that by De Morgan's Law, when 1Ḡ = 0 and Din = 1, exactly the addressed channel output evaluates to 0 (LOW) while all other three outputs remain 1 (HIGH).

Practical Applications

Common industrial and computational applications of 1:4 demultiplexers.

Microprocessor Memory Bank Selection

Decodes high-order address bits to assert the active-low Chip Select (/CS) pin of four distinct RAM/ROM memory banks without external inverters.

Serial-to-Parallel Data Demultiplexing

Converts incoming serial bit streams into four parallel output registers by stepping through select addresses S1, S0 with a synchronous clock divider.

Multi-Speaker / Audio Routing

Routes an audio or control clock signal from a single master DSP processor to one of four distributed amplifier quadrants or actuator driver modules.

7-Segment Display Digit Scanning

Used to drive common-anode or common-cathode multi-digit LED displays in time-multiplexed instrumentation dashboards.
