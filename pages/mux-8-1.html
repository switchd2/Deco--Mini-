IC 74151 8-to-1 Data Selector

8:1 Multiplexer

The 74151 is an 8-line to 1-line multiplexer that selects binary data from one of eight input channels (D0 through D7) and delivers it to dual complementary outputs: a true non-inverted output Y and an inverted output W̄. Selection is dictated by a 3-bit binary address bus (S2, S1, S0). An active-low enable strobe (Ḡ) controls the entire circuit: when Ḡ = 1 (inhibited), output Y is clamped to 0 and W̄ is clamped to 1.

Data Inputs Active-High

D0 to D7

Eight data lines carrying input bits to be routed according to the select code.

Address Select Lines 3-bit Binary

S2, S1, S0

3-bit address bus (S2=MSB, S0=LSB) selecting binary channel 000 (0) through 111 (7).

Enable Strobe Active-Low

Ḡ (Pin 7)

Active-low strobe. When Ḡ = 0, normal multiplexing occurs. When Ḡ = 1, Y=0 and W̄=1.

Complementary Outputs Dual Rails

Y & W̄

Y delivers true data D[sel]; W̄ delivers inverted data D̄[sel] when enabled.

Boolean Expression & Logic Equation

The true output Y corresponds to the sum of minterms of the 3 select variables gated by the active data bits and the active-low enable strobe:

Y = Ḡ' · ∑ [ m_i · D_i ]   (for i = 0 to 7)
W̄ = Y' = ( Ḡ' · ∑ [ m_i · D_i ] )'

Expanded canonical representation: Y = Ḡ' · (S2'S1'S0'D0 + S2'S1'S0 D1 + S2'S1 S0'D2 + S2'S1 S0 D3 + S2 S1'S0'D4 + S2 S1'S0 D5 + S2 S1 S0'D6 + S2 S1 S0 D7)

Practical Applications

Key use cases for 8-channel multiplexers in digital logic systems.

Arbitrary 4-Variable Function Generator

By connecting three input variables to S2, S1, S0 and applying the fourth variable (or 0/1/inverted) to inputs D0–D7, any 4-variable truth table can be implemented using one single 74151 chip.

Analog/Digital Sensor Telemetry

Sequentially monitors 8 remote telemetry sensors or test points through a single communication channel using a 3-bit binary counter to scan all channels.

Hardware Lookup Tables (LUT)

Modern Field Programmable Gate Arrays (FPGAs) use multiplexer-based Look-Up Tables (LUT3 / LUT4) directly modeled after 74151 architectures to implement logic gates dynamically.

Byte-to-Bit Serialization

Transmits an 8-bit parallel byte from an internal register onto a high-speed serial bus, generating complementary polarity lines for differential signaling.
